선순씨 가계부 설치 방법 (갤럭시 / 안드로이드)

[1] 인터넷 주소 만들기 (무료, 처음 한 번만)
 1. github.com 에 가입하고 로그인합니다.
 2. 오른쪽 위 + 버튼 > New repository
    - Repository name: gagyebu
    - Public 선택 > Create repository
 3. "uploading an existing file" 링크를 누르고
    이 폴더 안의 파일과 icons 폴더를 통째로 끌어다 놓은 뒤 Commit changes
    (index.html, sw.js, manifest.webmanifest, icons 폴더, fonts 폴더)
 4. Settings > Pages > Branch 를 main / (root) 로 고르고 Save
 5. 1~2분 뒤 https://내아이디.github.io/gagyebu/ 주소가 생깁니다.

[2] 와이프 폰에 설치
 1. 갤럭시에서 Chrome 으로 위 주소를 엽니다.
 2. 화면의 "설치" 버튼, 또는 오른쪽 위 ⋮ 메뉴 > "앱 설치"(또는 "홈 화면에 추가")
 3. 홈 화면에 생긴 "가계부" 아이콘으로 실행합니다. 인터넷이 없어도 열려요.

[알아둘 점]
 - 기록은 와이프 폰 안에만 저장됩니다. GitHub 에는 앱 화면 파일만 올라가요.
 - Chrome 의 "인터넷 사용 기록 삭제 > 쿠키 및 사이트 데이터"를 지우면 기록도 지워집니다.
   한 달에 한 번 설정 > "백업 파일 보내기"로 카톡 나와의 채팅이나 구글 드라이브에 보관해 두세요.
 - 앱을 고치고 싶으면 GitHub 에 index.html 만 새로 올리면, 다음에 앱을 열 때 자동으로 바뀝니다.
